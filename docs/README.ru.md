# Codex Switch

Переключение ChatGPT-аккаунтов для Codex. Перед запуском видно, сколько лимита осталось у каждого аккаунта.

## Установка одной командой

```sh
brew install blankmeta/tap/codex-switch
```

Всё необходимое установится автоматически. Ничего копировать или менять в `.zshrc` не нужно.

## Первый запуск

```sh
CODEX_SWITCH_LANG=ru codex-switch
```

1. Выбери обычное подключение. Если нужен прокси — выбери VLESS и вставь ссылку от VPN-провайдера.
2. Войди в ChatGPT в открывшемся браузере, если ещё нет сохранённых аккаунтов.
3. Выбери аккаунт по номеру. Codex запустится.

При следующих запусках достаточно `codex-switch`. Если аккаунт уже выбран, нажми Enter.

**Добавить ещё один аккаунт:** `codex-switch login`.

**Посмотреть аккаунты и лимиты:** `codex-switch accounts`.

**Обновить лимиты:** `codex-switch accounts --refresh`.

**Изменить подключение:** `codex-switch setup`.

**Остановить прокси:** `codex-switch stop`.

Старые аккаунты codex-auth и VLESS-настройки из `~/.config/xray-codex/` подхватятся автоматически. Команда `codex-vpn` тоже остаётся доступной.

Лимиты могут быть сохранённым снимком: смотри время данных. Это остаток доступного использования, а не баланс токенов. Уже запущенные сессии Codex нужно перезапустить после смены аккаунта.
