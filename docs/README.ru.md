# Codex Switch

Аккаунты ChatGPT, лимиты и профили проектов для Codex.

## Установка

```sh
brew install blankmeta/tap/codex-switch
CODEX_SWITCH_LANG=ru codex-switch
```

Выбери подключение и войди в ChatGPT. Новая установка создаст профиль `personal`.

## Рабочий аккаунт

```sh
codex-switch login work
```

Войди в рабочий аккаунт в браузере. Затем в каталоге рабочего проекта:

```sh
codex-switch bind work
codex-switch
```

Нажми Enter: Codex запустится с профилем проекта. Если профиль один, дополнительного выбора нет.

В другом терминале можно одновременно запустить личный профиль:

```sh
codex-switch run personal
```

У каждого профиля отдельные авторизация и история. Допускается один процесс Codex на профиль; разные профили работают параллельно. Для продолжения истории рабочего профиля: `codex-switch run work -- resume`.

## Остальные действия

| Действие | Команда |
| --- | --- |
| Профили и сохранённые лимиты | `codex-switch profiles` |
| Обновить лимиты свободных профилей | `codex-switch profiles --refresh` |
| Статус для интеграций | `codex-switch status --json` |
| Снять привязку к проекту | `codex-switch unbind` |
| Настроить VLESS | `codex-switch setup` |
| Проверить подключение | `codex-switch doctor` |
| Остановить прокси | `codex-switch stop` |

Лимиты — снимок доступного использования с указанным временем. У запущенного профиля обновление использует кеш, чтобы не вмешиваться в авторизацию Codex.

## Если пользовался предыдущей версией

Пока нет новых профилей, `codex-switch` показывает прежние аккаунты. После создания профиля он открывает новый список. Старые аккаунты и история доступны через `codex-switch legacy`, продолжение истории — `codex-switch legacy resume`.

Для изолированного профиля нужно один раз войти через `codex-switch login <имя>`. Общие настройки, MCP, skills и история старого Codex в него не копируются. Старые данные остаются на месте. Legacy-режим по-прежнему меняет общий аккаунт и требует перезапуска существующих сессий после переключения.

VLESS-подключение общее: заверши использующие его сессии перед заменой сервера или остановкой прокси. Команда `codex-vpn` остаётся совместимым именем запуска.
