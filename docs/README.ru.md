# Codex Switch

Твои аккаунты ChatGPT, остатки лимитов и сессии Codex в одном меню терминала.

## Установка

```sh
brew install blankmeta/tap/codex-switch
codex-switch
```

Выбери **Add ChatGPT account**, войди в браузере и вернись в терминал. Codex запустится. Придумывать имя аккаунта и редактировать файлы не нужно.

Русский язык включается в **Settings → Language / Язык** и сохраняется. Можно запустить сразу по-русски: `CODEX_SWITCH_LANG=ru codex-switch`.

## Каждый день

Выбери аккаунт стрелками и нажми **Enter**. В строке виден остаток за пять часов и неделю; ниже — свежесть данных и время восстановления. **Esc** возвращает назад, **→** открывает действия аккаунта. В обычном текстовом терминале выбирай по номеру.

| Действие | Где найти |
| --- | --- |
| Добавить ещё аккаунт | Добавить аккаунт ChatGPT |
| Обновить остатки | Обновить лимиты |
| Продолжить работу | Продолжить сохранённую сессию |
| Запомнить аккаунт проекта | Настройки → Аккаунт для этого проекта |
| Дать имя «Рабочий» или «Личный» | Настройки → Управлять аккаунтами → Переименовать |
| Войти повторно | Выбрать аккаунт с пометкой «войти» |
| Настроить VLESS | Настройки → Подключение → Вставить VLESS-ссылку |

У добавленных аккаунтов отдельные авторизация, настройки и история. Рабочий и личный можно запускать в разных терминалах одновременно. В этой версии допускается один работающий процесс Codex на аккаунт. Занятый аккаунт остаётся виден; приложение предлагает вернуться в его терминал или выбрать другой.

Лимиты показывают сохранённые данные с указанием возраста. `—` означает отсутствие данных, `?` — окно уже должно было обновиться, нужна новая проверка. У работающего аккаунта приложение сохраняет прежние показатели. Автоматического переключения аккаунтов нет.

## Подключение по ссылке

Если прокси нужен для входа, настрой его на первом экране или через `codex-switch setup`. Вставь VLESS-ссылку от провайдера: приложение скроет ввод, проверит ссылку и соединение. Если сервер не отвечает, приложение вернёт прежние настройки. Перед заменой работающего прокси оно запросит подтверждение.

## Если пользовался прежней версией

Старые аккаунты остаются в общем списке с пометкой **прежний**. Они используют прежнюю общую историю и настройки. Добавление нового аккаунта их не скрывает.

Для отдельной истории выбери прежний аккаунт в управлении аккаунтами и **Создать отдельный вход и историю**. Понадобится войти один раз. Прежние MCP, skills, настройки и история не копируются и остаются доступны через прежнюю запись.

Удаление добавленного аккаунта требует подтверждения и удаляет его локальный вход и историю. Занятый аккаунт удалить нельзя. Прежние аккаунты из этого меню не удаляются.

Команды для скриптов и JSON сохранены: `codex-switch --help-all`. Имя `codex-vpn` остаётся совместимым именем запуска.
