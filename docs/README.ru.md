# Codex Lobby

Твои аккаунты ChatGPT и Claude, остатки лимитов и сессии в одном меню терминала.

## Установка

```sh
brew install blankmeta/tap/codex-lobby
cxl
```

На Windows и Linux используй [установщик](install.md). Python устанавливать отдельно не нужно.

Выбери **Добавить аккаунт → ChatGPT или Claude**, войди в браузере и вернись в терминал. Нужный CLI запустится; недостающие инструменты приложение установит само. Придумывать имя аккаунта и редактировать файлы не нужно.

Русский язык включается в **Settings → Language / Язык** и сохраняется. Можно запустить сразу по-русски: `CODEX_LOBBY_LANG=ru codex-lobby`.

## Каждый день

Выбери аккаунт стрелками и нажми **Enter**. В строке виден остаток за пять часов и неделю; ниже — свежесть данных и время восстановления. **Esc** возвращает назад, **→** открывает действия аккаунта. В обычном текстовом терминале выбирай по номеру.

| Действие | Где найти |
| --- | --- |
| Добавить ещё аккаунт | Добавить аккаунт → ChatGPT или Claude |
| Обновить остатки | Обновить лимиты |
| Продолжить работу | Продолжить сохранённую сессию |
| Запомнить аккаунт проекта | Настройки → Аккаунт для этого проекта |
| Дать имя «Рабочий» или «Личный» | Настройки → Управлять аккаунтами → Переименовать |
| Войти повторно | Выбрать аккаунт с пометкой «войти» |
| Настроить VLESS | Настройки → Подключение → Вставить VLESS-ссылку |

У добавленных аккаунтов отдельные авторизация, настройки и история. Рабочий и личный можно запускать в разных терминалах одновременно. В этой версии допускается один работающий процесс на аккаунт. Занятый аккаунт остаётся виден; приложение предлагает вернуться в его терминал или выбрать другой.

Лимиты показывают сохранённые данные с указанием возраста. Для Codex есть кнопка обновления. Claude передаёт лимиты во время работы; свежие показатели доступны через `/usage` внутри Claude. `—` означает отсутствие данных, `?` — окно уже должно было обновиться, нужна новая проверка. У работающего аккаунта приложение сохраняет прежние показатели. Автоматического переключения аккаунтов нет.

## Подключение по ссылке

Если прокси нужен для входа, настрой его на первом экране или через `codex-lobby setup`. Вставь VLESS-ссылку от провайдера: приложение скроет ввод, проверит ссылку и соединение. Если сервер не отвечает, приложение вернёт прежние настройки. Перед заменой работающего прокси оно запросит подтверждение.

## Если пользовался прежней версией

Старые аккаунты остаются в общем списке с пометкой **прежний**. Они используют прежнюю общую историю и настройки. Добавление нового аккаунта их не скрывает.

Для отдельной истории выбери прежний аккаунт в управлении аккаунтами и **Создать отдельный вход и историю**. Понадобится войти один раз. Прежние MCP, skills, настройки и история не копируются и остаются доступны через прежнюю запись.

Удаление добавленного аккаунта требует подтверждения и удаляет его локальный вход и историю. Занятый аккаунт удалить нельзя. Прежние аккаунты из этого меню не удаляются.

Команды для скриптов и JSON сохранены: `codex-lobby --help-all`. Короткая команда — `cxl`. Имена `codex-switch` и `codex-vpn` остаются совместимыми командами запуска. Прежний каталог аккаунтов остаётся на месте.
